## How to use a notebook

1. Open it with the launch link above (or in Colab).
2. Run everything once: on the Hub, *Kernel → Restart Kernel and Run All Cells*; on Colab, *Runtime → Run all*.
3. Move the sliders, click the buttons, answer the questions, and say why you chose what you chose.

The notebooks that use a language model (*Write with AI*, *Why Does AI Forget?*, *How Do Language Models Work?*) set themselves up. On the Hub the model is already provided; on Colab the first run downloads it (about 0.8 GB, roughly 3–5 minutes).

## A note about the questions in the notebooks

Each notebook has a short check at the start and a similar one at the end, plus a few quick prediction and quiz questions. They are optional and nothing is graded. Answers are sent anonymously (a random code, no name or email) and are used only to learn whether the notebooks help and how to improve them.
