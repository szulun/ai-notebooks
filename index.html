Interactive notebooks · Intro to AI

Learn how AI works by changing it and watching what happens.

Six hands-on notebooks that turn ideas like temperature, memory, similarity, neural networks and model evaluation into sliders, buttons and short decisions. Run them in your browser, with nothing to install by hand.

Built by SzuLun (Zoey) Huang, UC Berkeley Data Science, under the guidance of Eric Van Dusen.

How to use a notebook

Each notebook is self-contained. Open one, run it once, then play.

  1. Open it

    Pick Open in Colab below, or use the JupyterHub link your instructor gave you.

  2. Run everything once

    JupyterHub: Kernel → Restart Kernel and Run All Cells.
    Colab: Runtime → Run all.

  3. Play and explain

    Move the sliders, click the buttons, answer the questions, and say why you chose what you chose.

If something looks stuck: refresh the page and run everything again. Run the cells from top to bottom rather than one at a time.

The notebooks

Start anywhere. Each one takes a single idea and lets you test it.

About this project

These notebooks are teaching materials for introductory AI courses, designed so that students without a programming background can still explore how models behave, compare results, and practise explaining their choices.

They were developed at UC Berkeley by SzuLun (Zoey) Huang under the guidance of Eric Van Dusen. Feedback and suggestions are welcome through the repository's issues.
